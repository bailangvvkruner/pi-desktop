# Pi Desktop 0.1.7

## 项目与侧栏

- 支持将电脑中的一个或多个文件夹拖入窗口添加项目，重复目录自动合并，保留当前会话和草稿。
- 项目菜单和右键菜单支持置顶；顶部独立“置顶”区同时容纳项目与对话，切换分组方式后不会重复显示。
- 按项目查看时，未归属项目的对话集中显示在项目列表下方；对话行隐藏最后编辑时间和项目副标题。
- 保留项目展开状态与手动排序，修复拖动项目后取消置顶的位置异常。

## 对话体验

- 输入框共用发送／停止按钮，任务进行中自动切换为停止。
- 任务进行时默认 Enter 排队、Ctrl+Enter（macOS 为 ⌘Enter）引导当前任务；可在“设置 → 常规”修改默认动作，Shift+Enter 始终换行。
- 改进会话标题编辑、模型与项目选择、思考流和对话过程展示。
- 扩展的选择、确认、输入等交互集中显示在输入框上方，支持排队与收起，保留原有草稿。

## 稳定性修复

- 修复会话切换期间误发送或停止、连接切换后加载状态卡住，以及草稿最后一次编辑可能漏存的问题。
- 修复已完成的扩展输入重启后误恢复为待发送，以及运行环境关闭后仍可能启动模型请求的问题。
- 防止完整备份通过 Windows 路径别名覆盖原会话；修复搜索规则保存到错误项目、旧分组排序请求丢失分组的问题。
- 修改存储清理条件后，过期预览立即失效，确认清理仅执行当前预览。

Windows 安装版可通过软件内更新升级；便携版请下载新版替换。Linux 提供 AppImage 与 DEB。
