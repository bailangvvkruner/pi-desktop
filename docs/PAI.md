# pai 独立聊天窗口

Windows 的 `pai` 命令会在当前文件夹打开一个只保留聊天区域的 Pi Desktop 窗口。每次调用都可打开新的窗口，完整桌面窗口可以继续使用。

精简窗口保留新建对话和设置入口。每个窗口使用自己的活动会话与浏览器数据，不会抢占已打开窗口；关闭时退出该窗口对应的进程。空闲的数据配置会在下次启动时复用，保留外观和统计开关。模型凭据与会话记录继续存放在原有的 Pi 用户目录中。自动化调度和软件更新由完整桌面窗口负责。

“设置 → 常规 → 对话统计”提供四个独立开关。Token 数量来自 Pi 的实际用量；速度是最近任务的输出 Token 除以该任务运行时间，包含工具等待。会话时间累计各次任务的运行时间，不累计用户闲置时间。旧记录缺少计时信息时显示 `—`。

## 安装命令

开发时先构建项目，再把命令绑定到本仓库的构建结果：

```powershell
pnpm build
pnpm install:pai --dev
```

绑定到已经安装、支持 `--pai` 的 Pi Desktop 时，指定实际应用 EXE（不是安装包或卸载程序）：

```powershell
pnpm install:pai --exe "C:\Users\你的用户名\AppData\Local\Programs\Pi Desktop\Pi Desktop.exe"
```

脚本默认写入 `%APPDATA%\npm`，与 npm 的 Windows 命令一样生成 `pai.cmd` 和 `pai.ps1`。启动命令本身使用 Windows 自带 PowerShell，不依赖 Node。安装脚本需要 Node。可以通过 `--command-dir "D:\tools\bin"` 选择其他已经加入 PATH 的目录。脚本只会更新自己生成的文件，发现同名的其他命令时会停止。

`--dev` 绑定仓库的绝对路径；移动仓库后需要重新安装命令。`--exe` 绑定安装位置；正常原地软件更新不需要重装命令。升级到包含此功能的版本后才支持独立聊天模式。

## 使用

在 Windows 资源管理器打开本地文件夹，在地址栏输入 `pai` 后按 Enter。Windows 会把当前文件夹作为命令的工作目录；启动器读取该目录，并通过 `--pai --cwd <绝对路径>` 传给桌面应用，不需要资源管理器拼接额外参数。

也可以在终端中使用：

```powershell
pai
pai "D:\项目\带 空格的目录"
pai -Cwd "D:\项目\带 空格的目录"
```

项目路径包含中文、空格、`&`、`%` 或 `!` 时会完整保留。`pai` 只传递目录，不会把目录名称当作命令执行。

新加入 PATH 的目录需要新终端/资源管理器会话才能识别。如果 PowerShell 的本机执行策略禁止 `.ps1`，可使用 `pai.cmd`。命令处理器不能把 UNC 网络共享作为当前目录；网络共享请先映射盘符，或者从终端显式执行 `pai.cmd "\\server\share\folder"`。

## 将来的安装包集成

安装器可以把这些文件安装到应用独立的 `bin` 目录，并把该目录添加到当前用户 PATH；卸载时仅移除该目录。这可以避免覆盖 `%APPDATA%\npm` 中其他软件创建的命令。当前脚本提供明确的本地安装流程，尚未自动修改系统或用户 PATH。
